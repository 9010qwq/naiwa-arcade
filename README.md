# 奶蛙游乐场

八款可以直接在浏览器玩的奶蛙同人小游戏：端托盘、倒放推箱、憋笑潜行、笑声接力，以及弹珠、滑冰、叠塔和圈地。每款都有独立操作与短流程，随时暂停、重来。全程静音，无需账号。

计划公开地址：[奶蛙游乐场](https://9010qwq.github.io/naiwa-arcade/)。当前为发布候选，公开部署尚未核实。各游戏已完成的检查与未测范围见 [验证说明](VALIDATION.md)。

## 玩什么

| 游戏 | 内容 | 操作与目标 |
| --- | --- | --- |
| [奶蛙，端稳这桌](games/tray/index.html) | 6 段订单，每段 32 秒 | 拖动角色所在画面或支点滑块，点击「笑一下」；正品累计稳住 7 秒，错单按箭头送进回收口。键盘 ← → / A D 移动，↓ 回中，空格笑。 |
| [这笑能撤回吗](games/rewind/index.html) | 5 幕推箱谜题 | 方向键 / WASD 或方向按钮移动，空格笑着推箱，Z 倒放。倒放只带回奶蛙，箱子保持原位；全部箱子到目标后走到出口。R 重拍整关。 |
| [奶蛙，图书馆闭麦](games/library/index.html) | 4 间图书馆 | 点地面自动绕书架，或方向键 / WASD 移动；Shift 憋笑慢行，空格放声，X 停下。触屏可点按锁定憋笑，再单指移动。依次拿三张卡并到出口。 |
| [奶蛙笑声接力局](games/relay/index.html) | 5 栋公寓 | 点住户选人，再开窗、转喇叭、点火；键盘方向键选人，W 开关窗，H 转向，空格点火。每栋只有 3 次点火，后两栋要求两路笑声在 2.5 秒内到顶。 |
| [弹珠营业中](games/pegs/index.html) | 6 个弹珠盘面 | 鼠标或触屏拖动瞄准、松开发射，也可用角度滑块与发射按钮；← → / A D 调角度，空格发射。有限球数内笑醒全部金色目标，接球可返还一颗。 |
| [滑到哪算哪](games/slide/index.html) | 8 盘滑行谜题 | 方向键 / WASD、方向按钮或轻扫滑行；收齐点心并停在出口。空格选「笑到坐地」，选择中途停靠格后确认；每关两次急刹。Z 撤销，R 重开。 |
| [叠罗汉营业中](games/stack/index.html) | 12 层入门、18 层挑战两种模式 | 看准移动坐垫，点画面／落下按钮，或按空格 / ↓ 落下。偏出去的部分会被切掉；三连精准可稳住两层，逢 5 层留意笑场。 |
| [这块地我笑了](games/territory/index.html) | 3 张圈地图，目标 60% / 65% / 70% | 按住方向键 / WASD 或方向板移动，触屏场地可四向滑动并保持按住。离开安全区画线、接回后填色；收集笑气后按空格或按钮推开附近巡游者。 |

每款页面都有自己的暂停和重来按钮。多数游戏支持 P / Esc 暂停；倒放和滑行使用 Esc。浏览器本地保存各游戏的解锁或纪录，不保证保存进行到一半的局面；更换浏览器、地址或清除站点数据后，进度可能不同。

关卡数与规则可由代码确认。单局时长、学习成本和趣味尚不能用自动通关时间代替真人结论，详见 [验证说明](VALIDATION.md)。

## 本地启动

这是原生 HTML、CSS、JavaScript 静态网站。保留全部目录和资源即可，无需安装游戏依赖或执行构建。

```text
index.html
styles.css
hub.js
games.json
assets/
games/
  tray/       rewind/     library/    relay/
  pegs/       slide/      stack/      territory/
```

每个游戏目录都包含自己的 `index.html`、脚本、样式和素材。门户会读取 `games.json`，所以请通过本地 HTTP 打开整个合集；直接双击首页可能因浏览器限制无法读取游戏清单。

如果电脑已经安装 Python，在包含合集 `index.html` 的目录打开终端，运行：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

浏览器访问 [本地游乐场](http://127.0.0.1:8080/)。Windows 若使用 Python Launcher，可将命令中的 `python` 换成 `py`。关闭终端或按 Ctrl+C 停止服务。已有其他静态服务器也可直接指定这个目录。

## 静态部署与编辑

将上述目录整体作为静态网站发布根目录。所有游戏入口与资源应保留相对路径，适合放在 GitHub Pages 的仓库子路径下；不要只上传首页或遗漏 `assets/`。

网页中的 HTML、CSS、JavaScript 本身就是可编辑源码。玩法逻辑与关卡数据位于各游戏目录的规则脚本中；修改后刷新即可。门户是否开放某款游戏由 `games.json` 决定，只有完成整合的游戏才应标记为开放。
