素材说明

《这笑能撤回吗》是一款奶蛙同人小游戏，非官方作品。

角色外观参考用户提供的奶蛙图片。游戏里的呆脸、狂笑两幅角色姿态由内置 imagegen 生成，保留了黄橙色梨形身体、奶油肚皮、绿眼与暗色手脚。

纸舞台、箱子、目标、出口与效果由本项目绘制。全部界面文字是真实 HTML 或 Canvas 文本；未使用网站 GIF、第三方原声或在线字体。

本游戏没有外部运行依赖，也不发送数据。仅在当前浏览器保存关卡进度，使用独立的 naiwa-rewind-progress-v1 键。游戏不包含音频。

角色及相关第三方 IP 权利归各自权利人。生成图像不代表取得原 IP 授权。此处不为角色或生成素材授予 MIT 许可；原创代码许可由合集统一处理。
